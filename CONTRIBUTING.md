# Contribuindo

1. Crie uma branch a partir de `develop`.
2. Mantenha cada funcao com responsabilidade unica.
3. Nao versione segredos.
4. Execute `mvn clean verify` antes do push.
5. Atualize documentacao e Postman quando o contrato HTTP mudar.
6. Abra Pull Request com descricao, evidencias e impacto em cloud/custos.
